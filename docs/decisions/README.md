# Architecture Decision Records

Each major decision gets one numbered file: `NNNN-short-title.md`, with
**Context**, **Decision**, **Alternatives considered**, and **Consequences**.

Status is one of: `Proposed`, `Accepted`, `Superseded by ADR-XXXX`.
Accepted ADRs are never edited — they are superseded by new ones.
